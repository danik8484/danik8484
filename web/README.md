# לו"ז יומי – מערכת משימות לצוות

מערכת ווב קטנה (מותאמת לנייד, בעברית) לניהול לו"ז יומי של צוות: כל איש צוות רואה את הכרטיסייה שלו, מנהלים רואים את האנשי צוות שלהם, והמנהל הראשי רואה את כולם.

## מה יש במערכת

- **כניסה בקוד למייל** – בלי סיסמאות. כל איש צוות מקבל קוד בן 6 ספרות למייל שהמנהל הראשי מגדיר.
- **לוח יומי** – כרטיסייה לכל איש צוות. כרטיסיות שאין לך הרשאה לראות מוצגות מטושטשות (בלי נתונים אמיתיים).
- **משימות** – כל אחד מוסיף לעצמו, מנהל מוסיף לאנשי צוות שלו, וכל איש צוות יכול לשלוח בקשת משימה לכל איש צוות אחר בלי לראות את הלו"ז שלו. רשום מי הוסיף ומתי.
- **סדר בתוך הכרטיסייה** – משימות מההנהלה (מנהל ראשי או המנהל הישיר) למעלה, משימות שהאיש צוות הוסיף לעצמו באמצע, ובקשות מאנשי צוות אחרים בשורה נפרדת למטה.
- **"משימות ששלחתי לאחרים"** – מי ששלח בקשה רואה רק את הסטטוס של הבקשה שלו, לא את שאר הלו"ז של האיש צוות.
- **סטטוסים** – פתוח / בתהליך / הושלם. "בתהליך" מחייב פירוט מה בוצע ומה נשאר.
- **גרירה** – משימה שלא הושלמה עוברת אוטומטית ליום הבא עם סימון "נגררת X ימים".
- **מחיקה עם סיבה** – חובה לכתוב למה מחקו. הכל נשמר ביומן.
- **היסטוריה מלאה** – מי שינה מה ומתי, על כל משימה.
- **התראות לטלפון** – שני ערוצים: התראות דחיפה (Web Push, בלי שום הגדרה) והודעת וואטסאפ למספר הפרטי (דרך WhatsApp Business API, ראה למטה). כשמוסיפים לאיש צוות משימות, נשלחת הודעה אחת מרוכזת אחרי כמה דקות של שקט ("דני הוסיף לך 3 משימות") ולא הודעה על כל משימה. בסוף היום (20:00, ניתן לשינוי ב-`REMINDER_TIME`) נשלחת תזכורת למי שיש לו משימות שלא עודכנו. באייפון צריך קודם "הוסף למסך הבית". אין שליחה במייל.
- **משימת לידים** – משימה קבועה מסוג "לידים" (מוגדרת לרון ולאורי שפירא, ראשון עד שישי). בעדכון אפשר לרשום כמות שיחות, ולפתוח חלונית "נסלקים" עם שם לקוח וסכום לכל עסקה (פלוס להוספת עוד). הכמות מחושבת לבד, הכל מוצג בלוח ונשמר בהיסטוריה.
  - **TODO (DND CASH):** לחבר את רשימת הנסלקים למערכת DND CASH. הנקודות בקוד מסומנות `TODO(DND CASH)`.
- **תמונות** – לכל משימה אפשר לצרף תמונות מהמצלמה או מהגלריה (למשל הוכחת ביצוע). התמונות מוקטנות בטלפון לפני ההעלאה ונשמרות ב-Cloudflare KV.
- **משימות קבועות** – חוזרות בימים שנבחרו (למשל ניקיון כל יום). נוצרות אוטומטית כל לילה (Cron) גם אם אף אחד לא פתח את המערכת.
- **צפייה בימים קודמים** – חצים בלוח. משימה שהושלמה מאוחר יותר מוצגת כפי שהייתה באותו יום.
- **סיכום יומי למנהלים** – שורה אחת מעל הלוח: כמה הושלמו, בתהליך, פתוחות ונגררות.
- **רענון אוטומטי** – הלוח מתעדכן כל דקה וכשחוזרים לאפליקציה.
- **אפליקציה למסך הבית** – PWA עם אייקון. "הוסף למסך הבית" בטלפון וזה נפתח כמו אפליקציה.
- **יומן פעילות** – למנהלים: כל הפעולות בטווח תאריכים, כולל מחיקות.
- **ניהול משתמשים** – למנהל הראשי: שמות, מיילים, תפקידים ומנהל ישיר.

## הרשאות

| תפקיד | רואה ומנהל |
|---|---|
| מנהל ראשי | את כולם |
| מנהל | את עצמו ואת האנשי צוות שהוא המנהל הישיר שלהם |
| איש צוות | רק את עצמו |

עריכה/מחיקה של משימה: מי שהוסיף אותה, או המנהל הראשי. מנהל יכול למחוק משימה שאיש צוות שלו הוסיף לעצמו. משימה שמנהל נתן, האיש צוות לא יכול למחוק.

שינוי סטטוס: רק האיש צוות שהמשימה שלו או המנהל שלו. מי ששלח בקשה לאיש צוות אחר יכול לערוך או למחוק אותה, אבל לא לסמן אותה כהושלמה.

סימון "הושלם":
- משימה שהאיש צוות הוסיף לעצמו, או משימה קבועה (יומית): האיש צוות מסמן בעצמו. במשימה קבועה הפירוט לא חובה.
- משימה שמנהל או איש צוות אחר נתן: האיש צוות מסמן רק "בתהליך" עם פירוט. "הושלם" מסמן המנהל הישיר או המנהל הראשי.

משימות קבועות אפשר להגדיר רק לעצמך או לאנשי צוות שאתה מנהל.

## התראות בוואטסאפ (WhatsApp Business API)

ההודעות נשלחות ממספר עסקי של החברה למספר הפרטי של כל איש צוות (שמוגדר במסך "אנשי צוות"). זה עובד דרך WhatsApp Cloud API של Meta, וצריך להגדיר פעם אחת:

1. חשבון Meta Business ואפליקציה ב-https://developers.facebook.com עם מוצר WhatsApp.
2. לחבר מספר טלפון עסקי (מספר שלא רשום כרגע בוואטסאפ רגיל, או להעביר אותו).
3. ליצור תבנית הודעה (Message Template) בקטגוריה Utility, בעברית, עם פרמטר אחד בגוף ההודעה, למשל:
   `עדכון מלו"ז יומי: {{1}}` ולקרוא לה `task_update`. לחכות לאישור Meta (בדרך כלל דקות עד שעות).
4. להגדיר במערכת:
   ```bash
   npx wrangler secret put WHATSAPP_TOKEN        # System User access token קבוע
   npx wrangler secret put WHATSAPP_PHONE_ID     # Phone number ID מהאפליקציה
   ```
   ואם שם התבנית או השפה שונים: `WHATSAPP_TEMPLATE`, `WHATSAPP_LANG` ב-`wrangler.jsonc`.

עלות: הודעות Utility בישראל עולות אגורות בודדות להודעה, ו-1,000 ההודעות הראשונות בחודש חינם. עד שזה מוגדר, ההתראות מגיעות דרך Web Push בלבד.

## אבטחה

- קוד כניסה בן 6 ספרות, תקף ל-10 דקות, עד 5 ניסיונות לקוד (נספרים אטומית, גם בניסיונות מקבילים) ועד 20 קודים לשעה לכל מייל. הקודים נשמרים כ-hash, והתשובה זהה למייל רשום ולא רשום.
- קישורי כניסה חד-פעמיים ומנויי התראות קשורים ל-session: יציאה מהמערכת מנתקת גם את ההתראות במכשיר.
- נקודות ה-API מקבלות רק JSON, כך שטופס HTML מאתר זר לא יכול לשלוח אליהן.
- Session בעוגייה httpOnly + Secure + SameSite, תוקף 60 יום, נמחקת ביציאה או בהשבתת משתמש.
- כל ההרשאות נאכפות בשרת. כרטיסייה מטושטשת לא מקבלת שום נתון מהשרת.
- כותרות אבטחה (CSP, X-Frame-Options ועוד) בקובץ `public/_headers`.
- D1 שומר גיבוי אוטומטי (Time Travel) ל-30 יום אחורה.

## טכנולוגיה

- Cloudflare Workers + D1 (חינמי, מותר לשימוש עסקי, בלי הקפאות) + KV לתמונות
- Web Push עם מפתחות VAPID שנוצרים אוטומטית ונשמרים במסד הנתונים (אין סודות להגדיר)
- Cron כל 5 דקות: משימות קבועות, התראות מרוכזות, תזכורת סוף יום
- Hono (API) + Drizzle ORM
- React + Vite + Tailwind (צד לקוח)
- Brevo לשליחת קודי כניסה במייל (300 מיילים ביום בחינם)

## פריסה לאינטרנט (פעם אחת, כ-15 דקות)

1. **חשבון Cloudflare** (חינמי): https://dash.cloudflare.com/sign-up
2. **התחברות מהמחשב:**
   ```bash
   cd web
   npx wrangler login
   ```
3. **מסד הנתונים והטבלאות** נוצרים לבד: הפריסה הראשונה יוצרת את מסד הנתונים (D1) ואת אחסון התמונות (KV), והשרת יוצר ומעדכן את הטבלאות בבקשה הראשונה. אין להריץ `wrangler d1 migrations apply` מול מסד שהשרת כבר יצר.
4. **חשבון Brevo** (חינמי, לשליחת המיילים): https://www.brevo.com
   - אמת את כתובת השולח (Senders & IP → Senders → Add a sender).
   - צור מפתח API (SMTP & API → API Keys → Generate a new API key).
5. **הגדרת סודות:**
   ```bash
   npx wrangler secret put ADMIN_EMAIL      # המייל של המנהל הראשי (דני)
   npx wrangler secret put BREVO_API_KEY    # המפתח מ-Brevo
   npx wrangler secret put MAIL_FROM        # כתובת השולח שאומתה ב-Brevo
   ```
6. **פריסה:**
   ```bash
   npm run deploy
   ```
   בסוף מודפסת הכתובת, בסגנון `https://fitness-daily-tasks.<שם-החשבון>.workers.dev`.
7. **כניסה ראשונה:** היכנס עם המייל שהוגדר ב-`ADMIN_EMAIL` (או עם קישור כניסה חד-פעמי), עבור ל"משתמשים" והגדר מייל לכל איש צוות. מרגע זה כולם יכולים להיכנס.

### פריסה בלי חשבון Cloudflare (חשבון זמני)

ה-workflow `deploy-temporary.yml` ב-GitHub Actions פורס לחשבון Cloudflare זמני בלי שום פרטי התחברות, ומדפיס (מוצפן) קישור "אימוץ" של החשבון וקישור כניסה ראשון למנהל. צריך לאמץ את החשבון תוך 60 דקות, אחרת הוא נמחק. אחרי האימוץ הכל נשאר בחשבון שלך, ופריסות עתידיות נעשות עם `wrangler login` או עם `CLOUDFLARE_API_TOKEN` ב-GitHub.

כל עדכון עתידי: `npm run deploy` שוב.

**פריסה אוטומטית מ-GitHub (לא חובה):** צור ב-Cloudflare API Token (תבנית "Edit Cloudflare Workers" + הרשאת D1 Edit) והוסף אותו כ-secret בשם `CLOUDFLARE_API_TOKEN` במאגר (Settings → Secrets → Actions). מאותו רגע כל push ל-`main` מריץ בדיקות, מיגרציות ופריסה.

טיפ לנייד: פתחו את הכתובת בדפדפן ובחרו "הוסף למסך הבית". זה מתנהג כמו אפליקציה.
