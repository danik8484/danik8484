# לו"ז יומי – מערכת משימות לצוות

מערכת ווב קטנה (מותאמת לנייד, בעברית) לניהול לו"ז יומי של צוות: כל עובד רואה את הכרטיסייה שלו, מנהלים רואים את העובדים שלהם, והמנהל הראשי רואה את כולם.

## מה יש במערכת

- **כניסה בקוד למייל** – בלי סיסמאות. כל עובד מקבל קוד בן 6 ספרות למייל שהמנהל הראשי מגדיר.
- **לוח יומי** – כרטיסייה לכל עובד. כרטיסיות שאין לך הרשאה לראות מוצגות מטושטשות (בלי נתונים אמיתיים).
- **משימות** – כל אחד מוסיף לעצמו, מנהל מוסיף לעובדים שלו. רשום מי הוסיף ומתי.
- **סטטוסים** – פתוח / בתהליך / הושלם. "בתהליך" מחייב פירוט מה בוצע ומה נשאר.
- **גרירה** – משימה שלא הושלמה עוברת אוטומטית ליום הבא עם סימון "נגררת X ימים".
- **מחיקה עם סיבה** – חובה לכתוב למה מחקו. הכל נשמר ביומן.
- **היסטוריה מלאה** – מי שינה מה ומתי, על כל משימה.
- **משימות קבועות** – חוזרות בימים שנבחרו (למשל ניקיון כל יום).
- **יומן פעילות** – למנהלים: כל הפעולות בטווח תאריכים, כולל מחיקות.
- **ניהול משתמשים** – למנהל הראשי: שמות, מיילים, תפקידים ומנהל ישיר.

## הרשאות

| תפקיד | רואה ומנהל |
|---|---|
| מנהל ראשי | את כולם |
| מנהל | את עצמו ואת העובדים שהוא המנהל הישיר שלהם |
| עובד | רק את עצמו |

עריכה/מחיקה של משימה: מי שהוסיף אותה, או המנהל הראשי. מנהל יכול למחוק משימה שעובד שלו הוסיף לעצמו. משימה שמנהל נתן, העובד לא יכול למחוק.

## טכנולוגיה

- Cloudflare Workers + D1 (חינמי, מותר לשימוש עסקי, בלי הקפאות)
- Hono (API) + Drizzle ORM
- React + Vite + Tailwind (צד לקוח)
- Brevo לשליחת קודי כניסה במייל (300 מיילים ביום בחינם)

## הרצה מקומית

```bash
cd web
npm install
cp .dev.vars.example .dev.vars        # ערוך את ADMIN_EMAIL
npm run db:migrate:local
npm start                             # http://localhost:8787
```

במצב פיתוח הקוד מוצג על המסך במקום להישלח במייל.

בדיקות קצה-לקצה (דורש שהשרת המקומי רץ):

```bash
npx playwright test
```

## פריסה לאינטרנט (פעם אחת, כ-15 דקות)

1. **חשבון Cloudflare** (חינמי): https://dash.cloudflare.com/sign-up
2. **התחברות מהמחשב:**
   ```bash
   cd web
   npx wrangler login
   ```
3. **יצירת מסד נתונים:**
   ```bash
   npx wrangler d1 create fitness-daily-tasks
   ```
   הפקודה מדפיסה `database_id`. הדבק אותו ב-`wrangler.jsonc` במקום `REPLACE_WITH_YOUR_D1_DATABASE_ID`.
4. **יצירת הטבלאות:**
   ```bash
   npm run db:migrate:remote
   ```
5. **חשבון Brevo** (חינמי, לשליחת המיילים): https://www.brevo.com
   - אמת את כתובת השולח (Senders & IP → Senders → Add a sender).
   - צור מפתח API (SMTP & API → API Keys → Generate a new API key).
6. **הגדרת סודות:**
   ```bash
   npx wrangler secret put ADMIN_EMAIL      # המייל של המנהל הראשי (דני)
   npx wrangler secret put BREVO_API_KEY    # המפתח מ-Brevo
   npx wrangler secret put MAIL_FROM        # כתובת השולח שאומתה ב-Brevo
   ```
7. **פריסה:**
   ```bash
   npm run deploy
   ```
   בסוף מודפסת הכתובת, בסגנון `https://fitness-daily-tasks.<שם-החשבון>.workers.dev`.
8. **כניסה ראשונה:** היכנס עם המייל שהוגדר ב-`ADMIN_EMAIL`, עבור ל"משתמשים" והגדר מייל לכל עובד. מרגע זה כולם יכולים להיכנס.

כל עדכון עתידי: `npm run deploy` שוב.

טיפ לנייד: פתחו את הכתובת בדפדפן ובחרו "הוסף למסך הבית". זה מתנהג כמו אפליקציה.

## מבנה הקוד

```

  migrations/           סכמת מסד הנתונים + 5 המשתמשים הראשונים
  src/shared/           טיפוסים וחוקי הרשאות (משותפים לשרת וללקוח)
  src/worker/           ה-API (Hono על Cloudflare Workers)
  src/client/           הממשק (React)
  e2e/                  בדיקות Playwright
```
