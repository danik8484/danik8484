גיבוי לעצמך
GitHub: danik8484/dani-sync-locker, תיקייה לוז-יומי/. שם גם המדריכים ומסמך המשך העבודה למחשב השני.

הפרטים הרגישים (טלגרם, וואטסאפ, שעות) נשמרים במסד הנתונים דרך מסך "הגדרות", לא בקוד. המאגר בגיטהאב ציבורי, אז שום סיסמה לא נמצאת בו.

הכניסה שלך

  • אתה מחובר עם קישור הכניסה שקיבלת. החיבור נשמר במכשיר 60 יום. מומלץ להוסיף למסך הבית ולהפעיל התראות.
  • רוצה להיכנס ממכשיר נוסף? מהמכשיר המחובר: אנשי צוות ← דני שקנבסקי ← קישור כניסה, ושלח לעצמך.
  • ננעלת מכל המכשירים? בקש מקלוד להריץ את ה-workflow "Admin login link" (דחיפה עם הסימון [login-link]). הוא מנפיק קישור חדש מוצפן, שרק קלוד באותו מחשב יכול לפתוח.
  • אחרי חיבור הוואטסאפ (סעיף הגדרות), כל אחד נכנס גם בלי קישור: בוחר את השם, מקבל קוד לוואטסאפ.

הכנסת הצוות

חמישה אנשי צוות כבר קיימים במערכת. חסרים רק הטלפונים והמיילים.

  1. 1
    תפריט ← אנשי צוות ← לוחצים על השם ← ממלאים טלפון נייד ומייל ← שמירה. הטלפון הוא המספר שאליו ילכו קודי הכניסה והתזכורות.
  2. 2
    לכל איש צוות: קישור כניסה ← וואטסאפ. נפתחת הודעה מוכנה עם הקישור. הקישור חד-פעמי, תקף שבוע.
  3. 3
    שולחים יחד עם מדריך השימוש (יש קובץ נפרד לרון; לשאר הצוות אותו מדריך מתאים, בלי החלק על אורי שפירא).

מסך הגדרות

תפריט ← הגדרות. שלושה חלקים.

1. טלגרם (הפיד שלך על כל שינוי)

  1. 1
    בטלגרם: חפש @BotFather ← /newbot ← תן שם ← העתק את ה-token.
  2. 2
    שלח הודעה כלשהי לבוט החדש (למשל "היי").
  3. 3
    בהגדרות: הדבק את ה-token ← שמירת הגדרות ← זהה צ'אט (ממלא לבד את ה-Chat ID) ← שלח בדיקה.

מרגע זה כל הוספה, שינוי סטטוס, עריכה, מחיקה, תמונה, נסלק ותזכורת מגיעים אליך לטלגרם עם פירוט מלא ומי ביצע.

2. וואטסאפ (מהקו העסקי של החברה)

בוחרים מצב גשר Baileys (הקו הקיים) וממלאים שלושה שדות:

  • כתובת הגשר (WA_HOST): הכתובת של שירות הגשר ב-Railway, מתחילה ב-https.
  • מזהה מכשיר: 7107645253 (הקו העסקי).
  • טוקן: הערך של BIZ_TOK או BRIDGE_TOKEN מ-Variables של השירות ב-Railway, או מהקובץ .env בתיקיית thedani-baileys-bridge במק.

שמירת הגדרות ← שלח בדיקה לוואטסאפ שלי. כשההודעה מגיעה, כל קודי הכניסה והתזכורות פעילים לכל הצוות.

3. תזכורות יומיות

שעה לכל יום בשבוע. ברירת המחדל: א׳–ה׳ 21:00, שישי 14:00, שבת 19:00 (הוספת משימות לשבוע). כפתור איפוס מחזיר לברירת המחדל.

איש צוות יכול לסגור בעצמו רק משימות שהוסיף לעצמו ומשימות קבועות. כל השאר: הוא מסמן "בתהליך" עם פירוט, ואתה (או המנהל הישיר) מאשרים ב"הושלם".

השגרה היומית שלך

  • בבוקר: להוסיף משימות לאנשי הצוות. משימה דחופה שולחת הודעה מיידית לבד. משימות רגילות מגיעות להם בהודעה מרוכזת אחת אחרי כמה דקות.
  • במהלך היום: הטלגרם מעדכן אותך על כל שינוי. אין צורך לפתוח את הלוח.
  • בערב: אחרי התזכורת של 21:00, עוברים על הלוח. שורת סיכום היום מעל הכרטיסים מראה כמה הושלמו, בתהליך, פתוחות ונגררות. משימות בתהליך עם פירוט טוב מסמנים "הושלם"; מה שלא, נגרר למחר עם ספירה.
  • נסלקים: העמוד נסלקים בתפריט מרכז את כל העסקאות של רון ואורי שפירא לפי טווח תאריכים, עם סה"כ כללי ולפי אמצעי תשלום.
  • שבת: אחרי התזכורת של 19:00 כולם אמורים להוסיף את המשימות ההכרחיות לשבוע. ביום ראשון בבוקר בודקים שזה קרה.

מה עוד נשאר לחבר

1. וואטסאפ: להכניס בהגדרות את כתובת הגשר והטוקן (סעיף הגדרות למעלה). בלי זה אין קודי כניסה בוואטסאפ ואין תזכורות, ורק קישורי כניסה עובדים.
2. טלגרם: ליצור בוט ולהדביק את ה-token בהגדרות.
3. אנשי צוות: להכניס טלפון ומייל לכל אחד ולשלוח קישורי כניסה.
4. DND CASH: לחבר את הנסלקים למערכת DND CASH. הנקודות בקוד מסומנות TODO(DND CASH).
5. אבטחה: מפתח ה-API של Cloudflare הודבק בצ'אט במהלך ההקמה. מומלץ להחליף אותו: Cloudflare ← My Profile ← API Tokens ← Roll, ואז לעדכן את הסוד CFTOKEN בגיטהאב (Settings ← Secrets and variables ← Actions).

להמשך עבודה במחשב השני

הכל בענן. במחשב השני פותחים קלוד ואומרים לו:

"תוריד מהענן את לוז-יומי מ-dani-sync-locker ותקרא את README.md שם. זה מסמך ההמשך עם כל מה שנבנה ומה נשאר."

או ישירות מהקוד החי:

git clone -b claude/hi-l4avs8 https://github.com/danik8484/danik8484
cd danik8484/web
npm install
npm run start      # בונה ומריץ מקומית על http://localhost:8787
npm run test:e2e   # 22 בדיקות אוטומטיות

כל שינוי שנדחף לענף claude/hi-l4avs8 עולה לאוויר לבד תוך כשתי דקות. הבדיקות רצות לפני הפריסה, ופריסה שנכשלת לא מחליפה את הגרסה החיה.
